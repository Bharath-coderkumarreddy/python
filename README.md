# Survey Feedback Analyzer

This project is a Python-based **Survey Feedback Analyzer** developed using Jupyter Notebook.

## Features

- Stores survey participant names, feedback, ratings, and serial numbers.
- Allows users to add new feedback records.
- Cleans feedback text by:
  - Converting text to lowercase
  - Removing punctuation
  - Removing extra spaces
- Counts the number of feedbacks containing specific words:
  - good
  - poor
  - excellent
- Calculates the average rating.
- Finds the feedback with the longest comment based on word count.
- Creates a list of unique words from all feedback comments.

## Technologies Used

- Python
- Jupyter Notebook

## How to Run

1. Open the Jupyter Notebook.
2. Run the cells in order.
3. Enter the number of new feedback records.
4. Enter the name, feedback, and rating for each new record.
5. View the analysis results.
